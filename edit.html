料金表を直接編集

公開中の料金表

公開には、GitHubで新しく作るトークンが必要です。ログインパスワードとは別で、github_pat_ で始まる長い文字列です。作った直後の画面で一度だけ表示され、あとから同じ文字列を見返すことはできません。いま入っている文字列を入れ直しても、拒否されたままです。

  1. GitHubで新しいトークンを作るを開く。ログインは ogawajimushoy-source です。名前の「料金表」と、下の「内容」の権限は入った状態で開きます。
  2. 「リポジトリ アクセス」で「リポジトリの選択のみ」を選び、「選択されたリポジトリ」から recruit-video-menu だけを選ぶ。
  3. ページ下の「アクセス許可」を開く。「リポジトリのアクセス許可」にある「内容」の選択を「読み取りと書き込み」にする。英語のままなら Contents の Read and write です。
  4. 一番下の「トークンの生成」を押す。次の画面に github_pat_ で始まる長い文字列が1回だけ出るので、全部コピーする。この画面を離れると、同じ文字列は二度と表示されません。
  5. 下の欄の中身を全部消して貼り、「このトークンを確認して保存」を押す。使えると出たら「公開する」を押す。

料金表を読み込んでいます…
